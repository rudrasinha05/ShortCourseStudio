# Short Course Studio course format

Each course is a single module with five three-hour sessions (15 hours total), one course listing and one registration. The assigned instructor decides the day-by-day syllabus, teaching material and labs. Publish specific topics after the instructor provides them.

| Course | Instructor | Duration |

For course exercises, create purpose-built sample datasets. Define expected outputs and validation checks before running exercises. Use those checks to verify results and revise any exercise that fails them.
